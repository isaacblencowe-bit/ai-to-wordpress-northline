# Editing guide

In Pages → Edit with Elementor, select Heading/Text Editor widgets to change copy, Image widgets to choose Media Library replacements, and normal Button controls to change labels/links. Select a container for spacing, direction, alignment and backgrounds. Use Elementor responsive controls and inspect all breakpoints before saving. Preserve the `nl-*` classes and demo action IDs: CSS and JavaScript depend on them.

Hero/image crops, architectural overlays and some precise typography/layout refinements remain theme CSS. Elementor controls cannot override every explicit theme rule. Hero imagery remains a native Image widget; no photographs are permanently embedded in CSS.

Header/footer are not Elementor Theme Builder templates. Use Appearance → Menus for navigation; Customizer → Site Identity for a logo and Northline header and footer for wordmark, CTA, statement and disclosure. Some footer layout and foundations require CSS edits. The copyright year is editable text, not an automatic year.

Use Elementor Site Settings for global palette and typography, but theme CSS also declares foundation colours and Arial; broad branding changes require reviewing both. Setup writes matching global kit settings. Do not rerun setup as a content reset.

The homepage demo opener/closer have special IDs and behaviour: edit their labels and panel copy, but do not repurpose their destinations as ordinary links. Contact details are Elementor text. WPForms fields, choices, notification and confirmation settings live in WPForms → All Forms. Widget Style controls hold the form appearance.

Keep Contact notifications disabled for demos and use synthetic data. Before a real launch, replace every fictional detail, configure actual delivery and privacy practices, and test them separately. No valid business address, licence, ABN, review or credential is supplied by this project.
